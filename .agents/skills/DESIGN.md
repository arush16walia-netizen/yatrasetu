# Yatra Setu Visual Language (DESIGN.md)

## Color Palette
- Primary Accent: #E65100 (Heritage Amber / Deep Saffron)
- Secondary Accent: #004D40 (Teal / Deep Emerald)
- Backgrounds: #FAFAFA (Light mode) / #0B0F17 (Dark surface)
- Surface Cards: #FFFFFF with subtle borders (#E5E7EB)

## Typography
- Display: Sans-Serif Bold (48px - 64px)
- Headings: Semi-bold (24px - 36px)
- Body: Inter / System UI Regular (14px - 16px)

## Guidance
- Use structural layouts inspired by modern travel platforms.
- Emphasize visual cards with real trip context over decorative filler text.
