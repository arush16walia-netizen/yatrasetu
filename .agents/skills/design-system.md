# Yatra Setu Design System & Quality Rules (Taste + Impeccable)

## Product Identity
- Application: Yatra Setu (Indian travel & itinerary platform).
- Tone: Premium, modern, highly functional, trustworthy.

## Anti-AI & UI Quality Rules (Impeccable)
1. Hierarchy & Contrast: No dull gray-on-gray text. Ensure high contrast ratio and clear font scaling.
2. Anti-AI Tells: Avoid plain 3-column card grids, default drop-shadows, and generic pill buttons without micro-interactions.
3. Component States: Every interactive element MUST have distinct hover, focus, and active visual states.
4. Spacing: Follow an 8px grid system for layout padding and gaps (8px, 16px, 24px, 32px, 48px).

## Design Taste Rules (Taste v2)
- DESIGN_VARIANCE: 8 (Use expressive, non-generic asymmetrical grid layouts for landing components).
- MOTION_INTENSITY: 6 (Subtle entrance transitions, smooth Lenis scrolling, Framer Motion spring hovers).
- VISUAL_DENSITY: 6 (Spacious travel itineraries with clear content hierarchy).
